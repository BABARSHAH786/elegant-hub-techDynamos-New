# Smart Document Analyzer

A powerful Python CLI tool that analyzes documents (PDF, DOCX, TXT) to extract insights, generate summaries, identify key information, and provide useful visualizations.

## Features

- **Multi-format Support**: Analyze PDF, DOCX, and TXT files
- **Text Extraction**: Extract and process text from various document formats
- **Document Summarization**: Generate concise summaries of document content
- **Keyword Extraction**: Identify the most important terms in the document
- **Sentiment Analysis**: Determine the emotional tone of the document
- **Entity Recognition**: Extract dates, numbers, emails, and URLs
- **Readability Metrics**: Calculate reading ease and complexity scores
- **Search Functionality**: Find specific information within documents
- **Visualization**: Generate charts for word frequency and sentiment analysis
- **Report Generation**: Create comprehensive analysis reports in console or JSON format
